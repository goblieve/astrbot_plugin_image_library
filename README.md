# 图片收藏调用工具（AstrBot 插件）

为 AstrBot v4.29.4、`aiocqhttp` 和个人微信 `weixin_oc` 提供本地图片、视频收藏、分类查看与 WebUI 管理。

## 功能

- 在 QQ 或个人微信私聊中由 AstrBot 管理员手动收藏附图/视频，或回复含图片/视频的消息后收藏。个人微信适配器支持的消息类型以 AstrBot 文档为准。
- 内置 `待处理`、`cos人像`、`风景`、`梗图`、`NSFW` 分类；未指定分类时收藏到 `待处理`，聊天收藏使用的未知分类会自动创建。
- 图片和视频使用同一个分类与编号体系；按分类随机查看媒体，也可按编号查看指定媒体。
- 支持 JPG、PNG、GIF、WebP、BMP 图片，以及 MP4、MOV、3GP、AVI、MKV、WebM 视频。
- WebUI 支持多选图片/视频导入、分页浏览、批量移入回收站、还原或彻底删除，以及将所选媒体移动到其他分类。
- 图片与视频卡片预览会缓存为小尺寸缩略图，避免每次翻页重新解码原始媒体。
- 管理页支持跨分类重复项检查：以 SHA-256 检测完全相同的图片/视频，并以 64 位感知哈希发现跨分类相似图片；结果仅供人工检查，可批量移入回收站，不会自动删除。
- 超过入库目标体积的媒体会尝试自动压缩；静态图片转为 JPEG/WebP，视频转为 H.264/AAC MP4。只处理插件临时副本，无法压到目标体积时会拒绝入库。超大静态 JPEG 会在压缩前请求半尺寸解码降采样；图片最大支持 1.6 亿像素，超大非 JPEG 图片或超出安全像素上限的动图可能需要先缩小。
- 图片与视频支持在详情页维护单项手工标签、在批量操作栏维护多项标签，也可按标签筛选当前分类；聊天支持“搜图”和语义搜索。
- 标签管理页支持维护同义别名和可选父子层级；别名用于搜图匹配和手工标签录入提示，父标签搜索会覆盖子标签。新增关系不会自动改写已有标签；批量规范化需先预览并明确确认。
- 管理页卡片可打开详情，查看完整描述及 AI/手工标签，并手动编辑描述、手工标签和删减 AI 标签；编辑后会尝试更新该媒体的语义向量。
- SFW 媒体收藏或导入到普通分类后自动请求所选视觉模型生成描述和 AI 标签；`待处理` 视为未分类，不自动发送，移入普通分类后开始评估。视频最多抽取 3 帧进行分析。
- 插件配置页可分别自定义 SFW 与 NSFW 的完整视觉评估提示词；默认值沿用当前提示词，自定义内容会整体替代对应默认提示词，不会与隐藏指令拼接。提示词需要模型返回 `description` 和 `tags` JSON 才能稳定维护 AI 标签。
- 详情页可清空 AI 描述和 AI 标签；清空时同时移除手动描述覆盖、保留手工标签。保存后可重新评估，安全媒体仍需先离开 `待处理` 分类。
- WebUI 语义检索会同时搜索 SFW 与 NSFW 索引；NSFW 媒体不会自动请求视觉模型，管理员需在 WebUI 选择模型后手动评估。
- 语义检索使用单独配置的 AstrBot Embedding 提供商；管理页可按 SFW/NSFW 范围批量重建索引，模型变更后无需重新生成视觉描述。
- 视频收藏或导入时会使用 FFmpeg 截取预览帧；旧视频会在首次打开管理列表时补生成。FFmpeg 不可用或视频无法解码时显示占位图。
- 管理页“AI 处理任务中心”集中显示超限压缩、视频预览图生成、AI 评估和语义索引任务的状态、进度与失败原因，支持取消进行中的任务和重试失败任务。
- AI 评估任务记录所用模型、提示词哈希版本及开始/结束时间；模型或提示词变更后可只重评版本过期的 SFW 媒体。NSFW 过期媒体仍需在任务中心手动选择模型并确认重评。
- 手动删除和聊天删除会把媒体移入回收站，可在 WebUI 还原或提前彻底删除；回收站在服务器本地时间每日 0 点自动清空。删除普通或默认分类时，其中媒体仍转入 `待处理`；如果目标分类已有相同文件，则保留一份并合并重复项。
- 媒体使用随机文件名存入插件数据目录，SQLite 保存分类与媒体索引；同一分类内按 SHA-256 去重。
- NSFW 聊天查看默认只允许 AstrBot 管理员；可在插件配置中额外放行 QQ 用户号、个人微信发送者 ID 或 QQ 群号。

## 指令

以下示例使用 AstrBot 默认命令前缀。若实例配置了其他唤醒前缀，请相应替换 `/`。

| 指令 | 用途 |
| --- | --- |
| `/图集 帮助` | 查看帮助 |
| `/分类` | 列出当前账号可查看的分类及媒体数 |
| `/收藏` | 收藏到 `待处理`（仅 AstrBot 管理员） |
| `/收藏 <分类>` | 收藏到指定分类；分类不存在时自动创建（仅 AstrBot 管理员） |
| `/看 <分类>` | 随机查看一张图片或一个视频 |
| `/看 <分类> <媒体编号>` | 查看指定图片或视频 |
| `/搜图 <标签关键词>` | 模糊匹配标签及其别名；搜索父标签时也会匹配子标签，随机返回一张图片或一个视频 |
| `/语义搜索 <画面描述>` | 语义匹配已索引内容，随机返回一张有权限查看的图片 |
| `/图集 删除 <媒体编号>` | 将媒体移入回收站（仅 AstrBot 管理员） |

`/图库` 是 `/图集` 指令组的别名，用于帮助和删除指令。其余指令为顶层命令，不需要添加“图集”。聊天收藏一次最多 20 个媒体；WebUI 上传按选中文件逐个处理，失败项不会阻止其余文件导入。大于 32 MB 的文件通过 8 MB 分块上传，并在服务端后台压缩和入库；上传页会轮询处理状态。重复文件会跳过。视频可在 QQ 或个人微信私聊中通过 `/看` 发送；WebUI 卡片显示视频预览图、格式和文件大小。

## WebUI

打开 AstrBot WebUI 的插件详情页，在插件视图中进入图集管理。管理页“刷新”旁的“AI 处理任务中心”显示压缩、视频预览生成、视觉评估和语义索引的进度与失败原因，允许重试失败项或取消进行中的任务。评估记录包含模型、提示词哈希版本和时间；任务中心会标出模型/提示词版本不匹配的旧评估，可只重评过期项；NSFW 重评需要手动选择模型并确认。可创建普通或 NSFW 分类，批量导入图片和视频，按页全选、反选、取消选择并批量移入回收站，或把所选媒体移动到另一个分类。通过“标签别名与层级”维护同义标签及父子关系；别名规则建立后即可用于搜图和录入建议，批量规范化会展示预览并再次确认。点击“重复项检查”可扫描全库跨分类 SHA-256 完全重复项及感知相似图片；相似阈值越大候选越多，也越容易出现误报。扫描结果可分页预览，并人工勾选后移入回收站。单张图片/视频的标签只在“详情”页编辑；勾选多项后可批量追加、替换或移除手工标签。详情页可编辑描述、手工标签并删减 AI 标签，也可清空 AI 描述和 AI 标签；清空时会一并移除手动描述覆盖并保留手工标签，保存后可重新评估。点击标签可筛选当前分类。语义检索同时覆盖有索引的 SFW 与 NSFW 媒体；可分别批量重建两个范围的索引。两个评估按钮位于批量操作栏，NSFW 人工评估使用已配置的 NSFW 默认模型，也可在提交时改选。已有描述的媒体会在评估队列中跳过。删除分类会把其中媒体移入 `待处理`；同分类的重复项会合并。`待处理` 是系统归档分类，不能删除。回收站支持逐项或批量还原、彻底删除和手动清空；未手动处理的项目会在服务器本地时间每日 0 点清空。

## 配置

- `compress_oversized_media`：超过图片或视频入库体积上限时是否自动压缩，默认开启；关闭后超限文件直接拒收。原始文件接收上限仍独立生效。
- `max_image_size_mb`：图片入库体积上限，默认 20 MB，范围 1–100 MB；超限时如何处理由 `compress_oversized_media` 决定。
- `max_video_size_mb`：视频入库体积上限，默认 100 MB，范围 1–100 MB；超限时如何处理由 `compress_oversized_media` 决定。
- `max_source_image_size_mb`：图片原始文件接收上限，默认 200 MB，最高 500 MB；超过后在压缩前拒收。
- `max_source_video_size_mb`：视频原始文件接收上限，默认 500 MB，最高 1000 MB；超过后在压缩前拒收。
- 视频自动压缩需要可用的 FFmpeg（系统 PATH 中的 ffmpeg，或 imageio-ffmpeg 提供的可执行文件）；压缩失败或仍超出目标时不会入库。图片压缩会调整编码质量，必要时缩小尺寸；透明图片和动图转为 WebP。图片像素上限为 1.6 亿；超过体积目标的超大 JPEG 会先请求半尺寸解码降采样，超大非 JPEG 图片可能需要先转成 JPG 或缩小。
- `sfw_evaluation_provider_id`：SFW 自动描述和打标签使用的聊天模型；须支持图片输入。留空时自动评估无法运行。
- `nsfw_evaluation_provider_id`：NSFW 后台人工评估的默认聊天模型；不会因此自动处理 NSFW 媒体。管理页面提交评估时仍可临时选择其他已启用的聊天模型。
- `sfw_evaluation_prompt`：SFW 完整视觉评估提示词，默认值为当前 SFW 指令；可自行替换。可选占位符 `{{media_context}}` 会被替换为图片或视频抽帧说明。
- `nsfw_evaluation_prompt`：NSFW 完整视觉评估提示词，默认值为当前 NSFW 指令；可自行替换。可选占位符 `{{media_context}}` 会被替换为图片或视频抽帧说明。
- `embedding_provider_id`：语义检索使用的 Embedding 模型，与聊天模型分开配置。配置或切换模型后，可在管理页分别重建 SFW、NSFW 索引。
- `nsfw_allowed_users`：允许在聊天中查看 NSFW 分类的 QQ 用户号或个人微信发送者 ID。
- `nsfw_allowed_groups`：允许查看 NSFW 分类的 QQ 群号；配置后群内成员均可查看。

NSFW 分类和媒体的聊天查看默认只允许 AstrBot 管理员或配置的 QQ/个人微信用户白名单；QQ 群白名单仍仅适用于 QQ 群聊。媒体移入普通分类后会清除自身 NSFW 标记；移入 `待处理` 时保留原标记。WebUI 展示媒体不使用聊天白名单；AstrBot WebUI 的访问权限仍由 AstrBot 自身负责。

模型数据边界：位于普通分类的 SFW 自动评估会发送图片或视频抽帧给 `sfw_evaluation_provider_id`。`待处理` 不自动评估，因此未分类内容不会默认发送。管理员手动评估 NSFW 时，所选媒体/抽帧会发送给管理页中当前选定的聊天模型（默认是 `nsfw_evaluation_provider_id`）；生成的文字描述之后会发送给配置中的 Embedding 提供商。批量重建索引会将所选范围已有的文字描述和 AI 标签发送给 Embedding 提供商，聊天语义搜索也会发送输入的文字查询。任务记录只存储提示词哈希版本，不保存完整提示词文本；记录会保存在插件 SQLite 数据库中。QQ 和个人微信语义搜索遵循 NSFW 聊天白名单，并只随机返回图片。请按这些服务的数据处理策略选择模型。

## 安装

将整个 `astrbot_plugin_image_library` 目录放入 AstrBot 的 `data/plugins/` 下，在插件管理中启用并重载。AstrBot 会根据 `requirements.txt` 安装 Pillow 依赖。插件数据位于 `data/plugin_data/astrbot_plugin_image_library/`，包含原图、SQLite 数据库和临时上传文件。

## 当前范围

此版本面向本地单实例图库：不自动收集群聊媒体，不做 OCR 或云同步。SFW 自动评估在后台串行执行；模型不可用时媒体收藏/导入仍会成功，并在卡片显示失败状态。媒体存储仍需纳入 AstrBot 数据目录的常规备份。
